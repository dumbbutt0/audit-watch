Tracks a finding through: Lead surfaced → Investigation safe → Converted → Severity gated → PoC handoff → Reproduced → Submission package → Human review → Submitted.

How to read this page (legend)
  • REPRODUCED does not mean SUBMITTED. An executable PoC existing only proves the bug — nothing was sent.
  • READY_FOR_HUMAN_REVIEW = human action required. Open the evidence, rerun the PoC, work the human gate.
  • SUBMITTED appears only from an explicit human outcome record — it is never inferred from "ready".
  • Scope, duplicate, and program severity are human-owned checks — shown PENDING until a human clears them.
  • Trust signals: Sev FP (post-gate) and Controls mis-promoted must stay 0. If either is non-zero, stop and investigate before trusting the page.

Operational: after code changes, restart python scripts/dashboard.py and hard-refresh /funnel to clear stale server modules and cached JS.
