## Root cause
claim treats a per-sharer action as if it owned the whole pooled position: it collects/settles the entire position's accrued value but accounts only the caller's share, with no mechanism to leave the other sharers' value in place or credit it internally. The other shares' checkpoints are never advanced, so their later settlement references value already removed.
