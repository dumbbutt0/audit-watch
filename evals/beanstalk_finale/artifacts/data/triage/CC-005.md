# Triage — CC-005

**Status:** submit  ·  **Severity:** Medium

**ICE:** I=Medium · C=Confirmed · E=Conditional

## Decision reason
Confirmed: the migration EIP-712 domain uses C.getLegacyChainId() (hardcoded 1) and address(this), and the struct hash covers only (owner, reciever, deadline) -- no nonce and no destination-L2 binding. A single owner signature is valid on any L2 deployment sharing the diamond address and the hardcoded legacy chainId, and carries no nonce to bound reuse. On a single-L2 deployment the practical replay is subsumed by CC-001, but the standalone scoping weakness (multi-deployment replay + absent nonce) is a distinct authorization-scoping Medium.

## Follow-up packet
Reachable: verifySignature on any L2 reusing the domain. No privileged keys (public sig). State: same sig validates across deployments. Guards fail: hardcoded chainId, no nonce, no L2 binding. Scope: cross-chain auth scoping. Medium standalone.
