## Disproof
To over-mint Beans in sunrise an attacker must inflate twaDeltaB within one block, but LibWellMinting.twaDeltaB reads ICumulativePump.readTwaReserves -- a season-length time-weighted average of cumulative reserves since the previous snapshot. A single-block flash-loan skew contributes negligibly to a season-length TWAP, and the minting oracle self-disables (deltaB=0) when twaReserves[beanIndex] < WELL_MINIMUM_BEAN_BALANCE or the USD oracle fails. The inverted-ternary getTokenPrice bug (BSA-001) is on the Chainlink source (not flash-manipulable) and the live BEAN:WETH/WSTETH wells price via LibEthUsdOracle/LibWstethUsdOracle, not the inverted branch, so it does not feed the live mint. Therefore no reachable single-tx path inflates the sunrise mint; the residual manipulable surface is the convert PENALTY spot path (FL-001), captured separately.
