# Triage — TI-001

**Status:** rejected  ·  **Severity:** Info

**ICE:** I=Info · C=High · E=Privileged

## Decision reason
Not safety-net code (token-pull accounting in a privileged-token path). LibFertilizer.addFertilizer credits the tokenAmountIn argument with a raw transferFrom and no balanceOf delta, which would drift only for a fee-on-transfer/rebasing Barn-Raise token. The Barn-Raise token is governance-controlled and currently wstETH (standard, non-FOT, reverts on failed transfer), so there is no live drift and the raw transferFrom cannot silently fail. Latent best-practice issue, no current impact. Rejected (Info-tier).

## Follow-up packet
